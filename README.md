# En Archē — Biblical Greek from zero

An interactive first course in Biblical (Koine) Greek, in a single HTML file.
Nine lessons take you from the alphabet to reading John 1:1–5 in the original,
with per-lesson quizzes, 60 high-frequency New Testament flashcards, and
paradigm reference tables.

## Run it

Open `index.html` in any browser. No build step, no dependencies, no server —
progress (lesson completion, quiz scores, flashcard stats) is saved in the
browser's localStorage.

## What's inside

- **Lessons 1–2** — the alphabet, breathing marks, accents, diphthongs
- **Lessons 3–5** — the article, the four cases, first and second declensions
- **Lesson 6** — present active verbs and εἰμί
- **Lesson 7** — prepositions and connecting words
- **Lesson 8** — John 1:1–5 with a tap-to-gloss interlinear
- **Lesson 9** — a twelve-month path onward (grammars, readers, daily tools)
- **Flashcards** — the 60 words that unlock most of the New Testament,
  missed cards resurface first
- **Reference** — alphabet, all 24 article forms, noun and verb paradigms,
  prepositions at a glance

Pronunciation follows the Erasmian classroom convention. Set in
[Cardo](https://fonts.google.com/specimen/Cardo), a typeface made for
biblical scholarship.
