# En Archē — Biblical Greek from zero

An interactive first course in Biblical (Koine) Greek, in a single HTML file.
Twenty-nine lessons take you from the alphabet through the full verb system,
reading real New Testament texts at every stage — with user profiles,
per-lesson quizzes, guided reading with translation practice, ~100
high-frequency flashcards, and paradigm reference tables.

## Run it

Open `index.html` in any browser (or serve it from GitHub Pages). No build
step, no dependencies, no server logic — all progress is saved per profile
in the browser's localStorage.

## What's inside

- **Lessons 1–8** — alphabet, breathing marks and accents, the article, the
  four cases, first and second declensions, present verbs and εἰμί,
  prepositions, and a first reading: John 1:1–5
- **Lessons 9–16** — pronouns, adjectives, the "I AM" sayings, imperfect,
  demonstratives, future, first and second aorist
- **Lessons 17–20** — reading John 1:10–12, middle voice and deponents,
  third declension, reading John 3:16–17
- **Lessons 21–28** — participles (present and aorist), infinitives,
  subjunctive, imperative, the Lord's Prayer, perfect and passive, and a
  capstone reading of 1 John 1:5–9
- **Lesson 29** — the road onward (grammars, readers, daily tools)
- **Reading tab** — six guided passages, each with a tap-to-gloss interlinear
  and a translate-it-yourself mode, plus a self-graded drill of twenty short
  famous verses
- **Flashcards** — ~100 high-frequency NT words; missed cards resurface first
- **Reference** — alphabet, all 24 article forms, all three declensions, the
  verb system at a glance, second aorists on sight, prepositions
- **Profiles** — several people can study in the same browser, each with
  separate progress

Pronunciation follows the Erasmian classroom convention. Set in
[Cardo](https://fonts.google.com/specimen/Cardo), a typeface made for
biblical scholarship.
